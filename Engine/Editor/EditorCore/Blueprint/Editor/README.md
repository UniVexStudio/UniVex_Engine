# Engine/Editor/EditorCore/Blueprint/Editor

Blueprint editor panels and UX (`editor_blueprint_panel.{h,cpp}`, `editor_panel_blueprint_script.cpp`, `blueprint_editor_services.{h,cpp}`): GraphEditor, NodeEditor, PinEditor, ConnectionEditor, NodePalette, DetailsPanel, VariablePanel, Search, ContextMenu, Clipboard, UndoRedo, Shortcuts, Visualization, and Accessibility. Compiled as part of `EditorCoreModule` (Entity Editor and Entity Class picker windows live under `Engine/Editor/EditorCore/Internal/shell/entity/`).
