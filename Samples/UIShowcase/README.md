# UI, Localization & Accessibility Showcase Sample

Demonstrates UniVex Engine's screen-space and world-space UI runtime:
- **Rich Text Markup** (`[color=#RRGGBB]`, `[b]`, `[i]`, `[size=N]`)
- **Unicode UTF-8 & BiDi/RTL Localization** (`ResolveVisualTextOrderUVE` + `UIFontFallbackChainUVE`)
- **Accessibility** (LMS Daltonization `ColorblindModeUVE`, live `uiScaleFactor`, and `IAccessibilityBridgeUVE` focus announcements)
- **9-Slice Widgets, Layout Containers & Tweens**
